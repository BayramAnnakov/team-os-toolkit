# team-os starter — a map, not a mandate

A lean starting *shape* for a Team OS brain, grounded in the structure `onsa-brain` converged on after months of real use. Delete what your team doesn't need; don't create a folder until content demands it.

## How to use it
1. **Best:** run `/init-team-os` (team-os-toolkit) to **mine** a real seed from your evidence — that gives you a CLAUDE.md + the 2–3 files that answer your #1 question. Then use THIS template as the map for where things grow next.
2. Or copy this folder, rename, and fill the stubs as you accumulate real content.

Every folder has a `CLAUDE.md` index (what lives here). Conventions: frontmatter (`owner` / `stability: stable|evolving|volatile` / `last_reviewed` / `sources`), kebab-case filenames, declarative grepable markdown. **Guard it like a constitution — add deliberately via PR, never let it become a dump.**
